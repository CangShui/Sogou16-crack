# 搜狗皮肤词库工具 - 编译说明

## 环境要求
- Go 1.21+（实测可用；不同 Go 版本产物字节可能不同，见文末说明）

## 编译（Windows amd64）
```bash
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 \
  go build -ldflags "-H=windowsgui -s -w" -o 搜狗皮肤词库工具.exe .
```

- `-H=windowsgui`：GUI 子系统，双击不弹黑框
- `-s -w`：去符号表，减小体积
- 零第三方依赖，纯标准库（syscall 调 Win32 API）

## 交叉编译（Linux/macOS 上编 Windows 版）
同上命令，任意平台可编。

## 稳定性要点（务必保留）
- `main()` 进入消息循环前必须调用 `runtime.LockOSThread()`。
  Go 会把消息循环 goroutine 在 OS 线程间迁移，而 Windows 要求消息泵固定在
  创建窗口的线程上；缺失会导致工具“打开一段时间后自动未响应”。
- 所有磁盘 IO / 子进程调用都放到后台 goroutine，结果经 `PostMessage` 回投 UI。
- 跨线程数据用互斥锁保护的全局变量交接，不经 `PostMessage` 传堆指针。
- 详见 `00_复刻指南.md` §6.4。
