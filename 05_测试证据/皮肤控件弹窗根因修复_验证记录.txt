# “皮肤组件升级”弹窗根因修复 验证记录
# 日期: 2026-09-16  VM 192.168.1.114

## 现象
装/应用动态皮肤时弹“皮肤组件升级 / 此皮肤需要新版皮肤控件支持”，
且动态皮肤无法正常应用。

## 定位过程
1. 弹窗文案（皮肤控件升级/动态皮肤/需要新版）确认在 SGTool.exe；
2. 注册表开关 Popup_DisableSkinBubble / EnableImePop 等实测无效；
3. 对比官方安装包：$_16_\SogouFlash_2.3.0.2553.scpf（13.5MB，zip；
   内含 SogouFlash.dll/64、SogouFlash.exe、SogouFlashDll*.dll、hwsignature.dll、
   ziplib*.dll 及 install.ini: folder=SogouFlash, version=2.3.0.2553, uid=1014）；
4. 官方安装器用 SogouComMgr.exe 注册该组件到
   Components\SogouFlash\<版本>\ + Components\ComponentConfig.ini；
5. 本精简包只装了 Components\SGDictation —— **漏装 SogouFlash 组件**，即根因。

## 修复（根因修复，无任何常驻进程）
- payload 增加 Components\SogouFlash\**（21 文件）+ Components\ComponentConfig.ini；
- scrub5 去公网字面量：patch 16 文件，verify 0 残留；
- 32 位 PE 注入 .nblk 网络钩子：SogouFlash.exe / SogouFlashDll.dll /
  sogouflashdll.dll / hwsignature.dll（64 位 DLL 依既有约定仅 scrub）；
- 删除此前的常驻守护“搜狗提示拦截.exe”及其自启键。

## 验证
- 纯文件拷贝部署（带 ComponentConfig.ini）→ 触发 skinRenderUpdate：弹窗 **无** ✅
- 完整安装包静默安装（EXIT=0）→ 组件 21 文件到位，Tools 下无守护：
  触发 skinRenderUpdate + 切换动态皮肤：弹窗 **无** ✅
- 皮肤切换写盘正常：SkinRecent.ini lastuse/lastunuse 正确更新
  （实测 13:01 连续切换 【ZX】极简黑→【雨欣】→三体→绽放 均落盘）
- 残留检查：无“搜狗提示拦截.exe”进程、无 SogouNoticeGuard 自启键 ✅
